**视频多轨道文本叠加功能**

**一、文本功能总控（共 3 行，每行对应 1 个独立文本轨道，结构完全一致）**

**文本 1 轨道（文本 2/3 轨道仅名称不同，功能、布局完全复用）**

**左侧：功能开关复选框 + 文字「文本 1」**（总控规则：勾选后该轨道的文本输入框、上下预览按钮、设置按钮、预览按钮全部激活可操作；未勾选时，该轨道所有组件均呈灰色，无法点击、输入或触发任何交互）。

**中间：文本输入与预览文本框**（支持中英文、数字、特殊字符输入，支持复制粘贴，输入内容实时显示）**+ 上下点击按钮**（两个独立按钮，分别标识「↑」「↓」；点击「↑」可向上滚动预览多段文本的上一行，点击「↓」可向下滚动预览下一行，无更多内容时按钮置灰不可点击）。

**右侧：功能操作按钮「设置」按钮**（采用差异化高亮配色 + 加粗样式，视觉突出；仅当轨道复选框勾选时可点击，未勾选时置灰）**+ 「预览」按钮**（采用蓝色等高饱和色 + 加粗样式，视觉突出；仅当轨道复选框勾选时可点击）。

点击「设置」按钮直接弹出「文字设置 - 文本 1」配置窗口，窗口为模态框（弹出后无法操作原界面，需关闭或确认后返回）。

点击「预览」按钮无需打开设置窗口，仅基于当前轨道的已配置信息（文本内容 + 默认样式 / 已保存样式）生成预览效果，点击后在当前页面弹出迷你预览窗口，实时展示文本在视频中的叠加效果，预览窗口支持关闭，关闭后返回原配置界面。

**二、「文字设置 - 文本 X」窗口（X=1/2/3，仅标题区分，内容完全一致）**

窗口左上角明确提示：「**文字设置 - 文本 X」**（X 为当前配置的轨道序号，便于用户区分），窗口为固定尺寸模态框，超出内容可通过窗口内滚动条查看。

**（一）核心文本来源模式（单选互斥，默认无选中状态；仅选中模式的专属参数亮显可操作，未选中模式的专属参数全部置灰，无法点击或输入）**

**1. 「文件名模式」**（单选框 + 文字「文件名模式」，点击单选框选中该模式）

核心功能定义：系统自动提取导入视频的基础文件名（不含文件路径、后缀名），将其作为文本叠加的原始内容，无需用户手动输入。

断行配置（同行从左到右依次排列，紧密对齐）：复选框 + 文字「以标点符号做断行」（点击复选框勾选后，后续两个关联参数激活；未勾选时，关联参数置灰不可操作）。「符号」标签 + 文本框（预设填充「。；：？！」5 个常用标点，支持用户手动删除、修改现有符号，或添加其他中英文标点 / 特殊字符，输入无长度限制）。「包括标点」复选框（参数前加复选框，勾选状态下断行后保留原文件名中的标点符号，未勾选则断行时自动剔除所有标点符号）。

断行效果示例（直观展示逻辑）：原视频文件名：「一户一宅实施，多少人算一户？多大面积算一宅？」勾选「包括标点」：断行后文本为三行 ——「一户一宅实施，」「多少人算一户？」「多大面积算一宅？」未勾选「包括标点」：断行后文本为三行 ——「一户一宅实施」「多少人算一户」「多大面积算一宅」

内容筛选（同行紧跟上述断行参数，从左到右依次排列）：「删除 / 保留」下拉框（点击展开选项，仅两个固定选项：「删除」「保留」，默认选中「保留」）+ 文本框（支持输入单个字符、字符串、标点符号等任意内容，作为筛选匹配的关键词）。固定文字「及之」（无交互，仅作为逻辑连接）+ 「前 / 后 / 间」下拉框（点击展开选项，仅三个固定选项：「前」「后」「间」，默认选中「前」）+ 固定文字「内容」（无交互，明确筛选范围）。

筛选交互规则：仅当「文件名模式」单选框选中时，该筛选参数组全部亮显可操作；未选中「文件名模式」时，整个参数组置灰，下拉框无法展开，文本框无法输入。

筛选功能示例（明确操作逻辑）：示例 1：下拉框选「删除」+ 文本框填「，」（逗号）+ 下拉框选「前」→ 筛选后删除逗号及其之前的所有文本内容。示例 2：下拉框选「删除」+ 文本框填「多少人」+ 下拉框选「前」→ 筛选后删除「多少人」及其之前的所有文本内容。示例 3：下拉框选「保留」+ 文本框填「“”」（双引号）+ 下拉框选「间」→ 筛选后仅保留双引号之间的文本内容（无引号则保留全部）。

**2. 「文件夹模式」**（单选框 + 文字「文件夹模式」+ 右侧小问号提示图标，点击单选框选中该模式）

小问号提示（点击图标弹出提示框，或鼠标悬浮时显示 tooltip，内容固定）：「顺序或随机选择文件夹下之 txt 文本文件应用。若勾选 [单行抽取]，则从所有 txt 文本内容中取一行使用。若勾 [空格换行]，则单行中空格后面文件换行显示」。

配置参数（同行从左到右依次排列，紧密对齐）：「文件夹」标签 + 文本框（只读状态，无法手动输入，仅用于展示选中的本地文件夹完整路径；路径过长时自动省略中间部分，鼠标悬浮时显示完整路径）。「选择文件夹」按钮（文字标识清晰，点击后弹出本地文件夹选择对话框，仅允许选择文件夹，不允许选择单个文件；选中文件夹后，路径自动填充至左侧文本框）。「随机应用」复选框（勾选后，系统从文件夹内所有.txt 文件中随机选取一个文件作为文本来源；未勾选时，按文件命名的字母 / 数字顺序依次选取）。「单行抽取」复选框（勾选后，从选中的.txt 文件中随机抽取一行文本作为叠加内容；未勾选时，提取文件内所有文本内容，包括换行符）。「空格换行」复选框（仅当「单行抽取」复选框勾选时激活可操作，未勾选时置灰；勾选后，抽取的单行文本中遇到空格时自动断行，未勾选则保持单行显示）。

配置交互规则：仅当「文件夹模式」单选框选中时，该参数组全部亮显；未选中时，整个参数组置灰，按钮无法点击，复选框无法勾选，文本框无路径显示。

**3. 「文本模式」**（单选框 + 文字「文本模式」+ 右侧小问号提示图标，点击单选框选中该模式）

小问号提示（点击图标弹出提示框，或鼠标悬浮时显示 tooltip，内容固定，分行展示更清晰）：「文本中的特殊标记：%{localtime} 将被替换为当前时间；%{pts:hms} 将被打上当前播放长度；%{duration} 被替换为视频长度；%{elapsed} 被替换为当前播放时长；%{remaining} 被替换为剩余播放时长；%{m} 会被替换成当前帧数；%{title} 被替换为视频文件名」。

配置参数（同行排列，文本框占比窗口宽度 80% 以上）：宽屏文本框（支持大段文本输入，默认显示 3 行高度，输入内容超过 3 行时自动显示右侧垂直滚动条；支持换行、回车，保留输入时的格式；支持复制粘贴多段文本）。上下滑动按钮（两个独立按钮，分别标识「↑」「↓」，位于文本框右侧；点击「↑」文本内容向上滚动一行，点击「↓」文本内容向下滚动一行；无更多可滚动内容时，对应按钮置灰不可点击）。

配置交互规则：仅当「文本模式」单选框选中时，文本框和滑动按钮亮显可操作；未选中时，文本框置灰无法输入，滑动按钮置灰无法点击。

**（二）位置与边距设置（单行从左到右依次排列，所有文本来源模式通用，不受模式切换影响，始终亮显可操作）**

「位置」标签 + 下拉框（点击展开选项，共 10 个固定选项：「上边」「下边」「左边」「右边」「左上」「右上」「左下」「右下」「中间」「随机」，默认选中「中间」；选择后文本按对应位置在视频中对齐，如「左边」= 文本左边缘与视频左边缘对齐，「随机」= 每次视频播放时文本位置随机生成）。

「X 边距」标签 + 文本框（支持手动输入非负整数，无输入时默认值为 0；输入非数字内容时自动提示「请输入有效数字」）+ 上下箭头按钮（两个独立按钮，标识「↑」「↓」，点击「↑」X 边距数值 + 1，点击「↓」X 边距数值 - 1，数值最小为 0，无法小于 0）。

单位切换按钮（默认显示「p」，代表像素单位；点击按钮切换为「%」，代表百分比单位，支持循环切换；按钮尺寸小巧，与输入框紧密对齐）+ 小问号提示（点击图标或鼠标悬浮显示 tooltip）：「决定 X 与 Y 边距是以像素还是百分比来表示，点击切换百分比模式：X 距以视频宽度计算，Y 距以其高度做计算」。

「Y 边距」标签 + 文本框（支持手动输入非负整数，无输入时默认值为 0；输入非数字内容时自动提示「请输入有效数字」）+ 上下箭头按钮（逻辑与 X 边距一致，数值最小为 0）+ 小问号提示（点击图标或鼠标悬浮显示 tooltip）：「X 边距对上边、中间、下边不起作用，Y 边距对左边、中间、右边不起作用」。

「行距」标签 + 文本框（支持手动输入正整数，无输入时默认值为 10；输入非数字内容时自动提示「请输入有效数字」）+ 上下箭头按钮（点击「↑」行距数值 + 1，点击「↓」行距数值 - 1，数值最小为 1，无法小于 1；数值越大，多段文本之间的垂直间距越大）。

**（三）字体样式设置（单行从左到右依次排列，所有文本来源模式通用，始终亮显可操作）**

**复选框 + 文字「字体」（点击复选框勾选后，「字号」参数激活可操作；未勾选时，「字号」参数置灰不可操作，其他参数不受影响）。**

字体下拉框（点击展开选项，内置常用字体：宋体、黑体、微软雅黑、Arial、Times New Roman 等，默认选中「微软雅黑」；支持手动输入字体名称搜索匹配，无匹配字体时显示「无结果」）。

「字号」标签 + 文本框（支持手动输入正整数，无输入时默认值为 24；输入非数字内容时自动提示「请输入有效数字」）+ 上下箭头按钮（点击「↑」字号数值 + 1，点击「↓」字号数值 - 1，数值范围 8-100，超出范围时自动提示「字号范围 8-100」；数值越大，文字显示越大）。

「颜色」标签 + 颜色下拉框（点击展开内置颜色面板，包含黑、白、红、蓝、绿等常用颜色，支持自定义色值输入（RGB/Hex 格式），默认选中「黑色」；选择后文字实时预览颜色变化）。

「透明度」标签 + 文本框（支持手动输入小数，无输入时默认值为 1.0；输入非数字或超出范围时自动提示「请输入 0.1-1.0 的数值」）+ 上下箭头按钮（点击「↑」透明度数值 + 0.1，点击「↓」透明度数值 - 0.1，数值范围严格限制在 0.1-1.0；数值越接近 1.0，文字越清晰（透明度越低）；越接近 0.1，文字越淡（透明度越高））。

阴影颜色下拉框（点击展开内置颜色面板，支持自定义色值输入，默认选中「黑色」；选择后文本自动添加对应颜色阴影，实时预览效果）。

描边颜色下拉框（点击展开内置颜色面板，支持自定义色值输入，默认选中「白色」；选择后文字边缘自动添加对应颜色描边，实时预览效果）。

「宽度」标签 + 文本框（支持手动输入正整数，无输入时默认值为 1；输入非数字或超出范围时自动提示「请输入 1-20 的数值」）+ 上下箭头按钮（点击「↑」宽度数值 + 1，点击「↓」宽度数值 - 1，数值范围严格限制在 1-20；数值越大，描边线条越粗）。

**（五）背景样式设置（单行从左到右依次排列，所有文本来源模式通用，始终亮显可操作）**

**复选框 + 文字「背景」（点击复选框勾选后，「透明度」「样式」「贴合」「边距」参数全部激活可操作；未勾选时，这些参数全部置灰不可操作）。**

背景颜色下拉框（点击展开内置颜色面板，支持自定义色值输入，默认选中「浅灰色」；选择后文本添加对应颜色背景，实时预览效果）。

「透明度」标签 + 文本框（支持手动输入小数，无输入时默认值为 0.8；输入非数字或超出范围时自动提示「请输入 0.1-1.0 的数值」）+ 上下箭头按钮（点击「↑」透明度数值 + 0.1，点击「↓」透明度数值 - 0.1，数值范围严格限制在 0.1-1.0；数值越接近 1.0，背景越清晰（透明度越低）；越接近 0.1，背景越淡（透明度越高））。

「样式」标签 + 下拉框（点击展开选项，仅两个固定选项：「填充」「默认」，默认选中「默认」；「默认」= 仅对文字本身区域添加背景色，不覆盖整行；「填充」= 对文本所在的整行区域添加背景色）。

「贴合」复选框（仅当「样式」下拉框选中「填充」时激活可操作，选中其他样式时置灰；勾选后，背景色仅贴合文本内容边缘（自适应文本长度），未勾选时背景色填充整行宽度）。

「边距」标签 + 文本框（支持手动输入整数，正负均可，无输入时默认值为 5；输入非数字时自动提示「请输入有效数字」）+ 上下箭头按钮（点击「↑」边距数值 + 1，点击「↓」边距数值 - 1，数值范围 - 20 至 50；正数 = 背景色超出文本边缘（数值越大超出越多），负数 = 背景色小于文本边缘（数值越小范围越小））。

**（六）滚动动态设置（单行从左到右依次排列，所有文本来源模式通用，始终亮显可操作）**

**复选框 + 文字「滚动」（点击复选框勾选后，后续所有参数全部激活可操作；未勾选时，这些参数全部置灰不可操作）。**

方向下拉框（点击展开选项，共 5 个固定选项：「向右」「向左」「向上」「向下」「随机」，默认选中「向右」；「向右」= 文本从左至右水平移动，「向上」= 文本从下至上垂直移动，「随机」= 每次视频播放时随机选择滚动方向）。

「速度」标签 + 文本框（支持手动输入小数，无输入时默认值为 1.0；输入非数字或超出范围时自动提示「请输入 0.01-20.0 的数值」）+ 上下箭头按钮（点击「↑」速度数值 + 0.1，点击「↓」速度数值 - 0.1，数值范围严格限制在 0.01-20.0；数值越大，文本滚动速度越快，越小则越慢）。

「随机速度」复选框（勾选后，系统对不同视频随机分配滚动速度，速度值范围为 0 至当前设置的「速度」数值；未勾选时，所有视频均按当前设置的「速度」数值滚动）+ 小问号提示（点击图标或鼠标悬浮显示 tooltip）：「对不同的视频，随机设置文本滚动速度值，其值范围在 0 与设定的速度值之间」。

「对角移动」复选框（勾选后，文本按对角方向滚动，如「右下」位置 +「向上」滚动 = 从右下往左上对角移动；未勾选时，文本按垂直 / 水平方向滚动）+ 小问号提示（点击图标或鼠标悬浮显示 tooltip）：「位置在中间随机、随机滚动情况下，对角移动不起作用」。

**（七）显示时序设置（单行从左到右依次排列，所有文本来源模式通用，始终亮显可操作）**

**「延时」标签 + 文本框（支持手动输入非负整数，无输入时默认值为 0；输入非数字时自动提示「请输入有效数字」）+ 上下箭头按钮（点击「↑」延时数值 + 1，点击「↓」延时数值 - 1，数值范围 0-300 秒，超出范围时自动提示「延时范围 0-300 秒」）+ 单位标识「秒」（固定显示，明确参数单位）。**

数值代表视频开始播放后，文本延迟多久出现，例：输入 5 = 视频播放 5 秒后文本显示。

「间隔」标签 + 文本框（支持手动输入非负整数，无输入时默认值为 1；输入非数字时自动提示「请输入有效数字」）+ 上下箭头按钮（点击「↑」间隔数值 + 1，点击「↓」间隔数值 - 1，数值范围 0-60 秒，超出范围时自动提示「间隔范围 0-60 秒」）+ 单位标识「秒」。

数值代表多段文本之间的显示间隔时间，例：输入 2 = 第一段文本显示后，间隔 2 秒再显示第二段。

「持续」标签 + 文本框（支持手动输入正整数，无输入时默认值为 5；输入非数字时自动提示「请输入有效数字」）+ 上下箭头按钮（点击「↑」持续数值 + 1，点击「↓」持续数值 - 1，数值范围 1-300 秒，超出范围时自动提示「持续范围 1-300 秒」）+ 单位标识「秒」。

数值代表每段文本在视频中停留的时长，例：输入 3 = 单段文本显示 3 秒后消失。

「行显」复选框（勾选后，多段文本按设定的「间隔」时间逐行显示，显示完一行再显示下一行；未勾选时，所有文本同时在画面中显示）。

「循环」复选框 + 小问号提示（点击图标或鼠标悬浮显示 tooltip）：「行显：多段文本，按设定的时间逐行显示。循环：文本是否循环显示。若不勾选，非单行文本显示一遍后全部消失，单行文本持续显示至视频结束；若勾选，文本显示完毕后重新开始显示，直至视频结束」。

**（八）窗口操作按钮（窗口底部通栏布局，从左到右依次排列，始终亮显可操作）**

「预览」按钮（采用蓝色等高饱和色 + 加粗样式，视觉突出）。

点击后在当前窗口上方弹出独立预览框，实时渲染所有参数配置后的文本效果。

预览框包含「关闭」按钮，点击关闭返回配置界面；预览过程中可切换配置窗口修改参数，预览效果实时同步更新。

「确定」按钮（采用标准配色 + 加粗样式）。

点击后保存当前窗口内所有参数设置，自动关闭配置窗口，返回原轨道配置界面，新设置实时生效。

「取消」按钮（采用标准配色 + 常规样式）。

点击后不保存任何参数修改，自动关闭配置窗口，返回原轨道配置界面，所有参数保持进入窗口前的状态。

**三、关键逻辑梳理（避免混淆，明确全局交互规则）**

**总控开关优先级：**文本轨道的「文本 X」复选框为该轨道最高优先级控制项，未勾选时，该轨道的文本输入框、上下预览按钮、设置按钮、预览按钮全部置灰不可操作，即使之前有配置记录也不会在视频中显示文本。

**模式与组件联动规则：**文本来源模式为单选互斥，仅选中的模式对应的专属参数组亮显可操作，未选中模式的专属参数组全部置灰，无法触发任何交互；通用参数（位置边距、字体样式等）不受模式切换影响，始终亮显可操作。

**前置条件约束规则：**子参数需依赖父功能复选框勾选才能激活，具体包括：

「符号」「包括标点」依赖「以标点符号做断行」勾选；

「字号」依赖「字体」勾选；

「深度」依赖「阴影」勾选；

「宽度」依赖「描边」勾选；

「背景透明度」「样式」「贴合」「边距」依赖「背景」勾选；

「贴合」依赖「样式」选择「填充」；

「空格换行」依赖「单行抽取」勾选；

「滚动速度」「随机速度」「对角移动」依赖「滚动」勾选。

**特殊生效规则：**

「对角移动」仅在「位置」选择「左上」「右上」「左下」「右下」且「滚动方向」选择「向右」「向左」「向上」「向下」时生效，位置为「中间」「随机」或滚动方向为「随机」时，即使勾选「对角移动」也不生效；

「X 边距」仅对「左边」「右上」「右下」「中间」「随机」位置生效，对「上边」「下边」「左上」「左下」位置不生效（修改数值无效果）；

「Y 边距」仅对「上边」「下边」「左下」「右下」「中间」「随机」位置生效，对「左边」「右边」「左上」「右上」位置不生效（修改数值无效果）；

文本模式中的特殊标记仅在视频播放时生效，预览时显示标记原文，播放时自动替换为对应动态内容。
