### 三、后端实现

#### 1. 去头尾实现 (`build_command`)
**实现逻辑：**
- 在 `-i` 之后，根据 `trim.mode` 添加裁剪参数
- 去头尾模式：`-ss [head]` + `-t [duration - head - tail]`
- 截取模式：`-ss [start]` + `-t [duration]`
- 异常值夹紧：duration ≤ 0 时跳过并输出警告

**位置**: `processor/batch_params_processor.py:1410-1441`

#### 2. 固定变速实现

**视频变速** (`_build_speed_filter`)：
- 使用 `setpts` 滤镜：`setpts={1.0/speed}*PTS`
- 集成到滤镜链中，位于文本滤镜之前
- 支持最短时长保护

**音频变速** (`build_command`)：
- 不变调：使用 `atempo`，支持级联（>2.0 或 <0.5）
- 变调：使用 `asetrate` + `aresample`
- 位置：滤镜处理之后，帧率调整之前

**位置**: 
- `processor/batch_params_processor.py:886-914` (视频滤镜)
- `processor/batch_params_processor.py:1530-1567` (音频滤镜)

#### 3. 分段变速实现 (`_build_segment_speed_command`)

**实现逻辑：**
1. 按 `segment_duration` 切分视频
2. 为每段随机生成速度（0.5-4.0）
3. 最短时长保护：计算期望总时长，若 < min_duration，对所有段速度统一缩放
4. 构建 `filter_complex`：
   - 视频：`[0:v]trim+setpts[v0]` ... → `concat=n=N:v=1:a=1[vout][aout]`
   - 音频：`[0:a]atrim+atempo/asetrate[a0]` ... → （同上）
5. 显式映射：`-map [vout] -map [aout]`

**特殊处理：**
- `atempo` 级联：速度超出 0.5-2.0 范围时多次应用
- 变调模式：使用 `asetrate` + `aresample`
- 独立路径：不支持同时应用其他复杂滤镜（已添加警告）

**位置**: `processor/batch_params_processor.py:1584-1699`

### 四、兼容性处理

#### 与现有功能的集成
- ✅ 去头尾：使用 `-ss`/`-t` 参数，不影响滤镜链
- ✅ 固定变速：集成到滤镜链，与水印、文本等正常共存
- ⚠️ 分段变速：走独立路径，其他滤镜不生效（已添加警告提示）

#### 滤镜执行顺序
```
输入 → 去头尾(-ss/-t) → 基础滤镜 → 变速 → 水印 → 文本 → 输出
```

## 技术要点

### 1. 最短时长保护算法
```python
expected_duration = video_duration / speed_value
if expected_duration < min_duration:
    speed_value = video_duration / min_duration
    speed_value = clamp(speed_value, 0.5, 4.0)
```

### 2. atempo 级联策略
```python
# atempo 单次限制 0.5-2.0
while speed > 2.0:
    apply("atempo=2.0")
    speed /= 2.0
while speed < 0.5:
    apply("atempo=0.5")
    speed /= 0.5
apply(f"atempo={speed}")
```

### 3. 分段变速随机种子
```python
random.seed(variant)  # 确保相同 variant 产生相同随机序列
for each segment:
    speed = random.uniform(0.5, 4.0)
```

## 已知限制

1. **分段变速限制**：不支持同时应用其他复杂滤镜，需分步处理
2. **速度范围**：0.5-4.0，超出会被夹紧
3. **精度损失**：分段变速多次编码可能轻微降低质量
4. **预览功能**：UI 有预览按钮但未连接实际逻辑（可后续补充）

## 后续优化建议
