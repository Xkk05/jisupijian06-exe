所有元素按 “从上到下分三行” 排列，每行内部按 “左→右” 顺序分布，复选框紧邻对应功能名称左侧，输入框 / 按钮与关联文字紧密相邻。

**第 1 行：主功能开关 + 预览按钮（核心控制行）**

**布局结构（左→右）：**

【□ 音视频变速】（复选框在左，“音视频变速” 文字在右，紧邻复选框）

预览按钮（位于该行右侧，与 “音视频变速” 功能同行，单独陈列）

**交互逻辑：**

未勾选 “音视频变速” 复选框：第 2 行、第 3 行所有功能（复选框、输入框、文字描述）均呈灰色，不可点击、不可编辑；

勾选 “音视频变速” 复选框：第 2 行、第 3 行所有功能解锁，支持正常操作；

预览按钮仅在 “音视频变速” 勾选后可点击，未勾选时呈灰色不可点；点击后预览当前设置效果（不含分段变速相关功能）。

**第 2 行：基础变速参数（变速倍数 + 最短时长）**

**布局结构（左→右）：**

“变速倍数：”（文字描述）

文本输入框（用于直接输入数值）

上下箭头调节按钮（垂直堆叠在文本输入框右侧，上箭头在上、下箭头在下）

【□ 最短时长】（复选框在左，“最短时长” 文字在右，紧邻复选框）

文本输入框（紧邻 “最短时长” 文字右侧）

“秒”（单位文字，紧邻最短时长输入框右侧）

**交互与参数规则：**

变速倍数：点击上箭头数值 + 0.1，点击下箭头数值 - 0.1，支持直接输入 0.5-4.0 范围内的数值（保留 1 位小数）；

最短时长：未勾选复选框时输入框不可编辑，勾选后可输入正整数；变速后视频时长若低于设置值，自动调整为该设置值。

**第 3 行：高级变速参数（分段变速 + 片段重组 + 变调）**

**布局结构（左→右）：**

【□ 分段变速】（复选框在左，“分段变速” 文字在右，紧邻复选框）

“每”（文字描述，紧邻 “分段变速” 右侧）

文本输入框（紧邻 “每” 字右侧）

“秒为一段”（单位文字，紧邻输入框右侧）

【□ 视频片段随机重组】（复选框在左，文字在右，紧邻复选框，与 “分段变速” 功能相邻）

【□ 变调】（复选框在左，文字在右，紧邻复选框，位于该行最右侧）

**交互逻辑：**

分段变速：未勾选时，其对应的输入框不可编辑，且 “视频片段随机重组” 的复选框 + 文字均呈灰色不可勾选；勾选后，输入框可输入正整数（用于设置分段时长），“视频片段随机重组” 解锁可勾选；

视频片段随机重组：勾选后，分段变速后的视频片段随机打乱重组，未勾选则保持原分段顺序；

变调：独立开关（不受分段变速影响），勾选后音频音调随变速比例同步变化，未勾选则音调不变。

**补充说明**

所有复选框样式统一，输入框样式统一，聚焦时可直观区分；

不可操作状态：所有不可点击 / 编辑的元素（复选框、输入框、文字、按钮）均呈浅灰色，与可操作状态的正常颜色形成明显区分；

预览限制：仅对 “变速倍数”“最短时长”“变调” 的设置生效，对 “分段变速”“视频片段随机重组” 不预览。
