第 2 页

一、引言

（一）编写目的

本说明书用于指导用户使用公司“极速批剪平台”。希望用户在使用系统过程中能够快速上手，起到“无师自通”的作用。本手册重点介绍系统主要功能及对应操作方法。

（二）背景

该系统由江西六角星科技有限公司开发，通过自动化和智能化方式提升工作效率并优化用户体验。

二、用途

（一）功能

极速批剪是一款面向办公、自媒体、短视频创作、素材整理等场景的批量剪辑工具。软件以“批量处理、极速成片、简单易用”为核心，支持批量导入视频与图片素材，一站式完成裁剪、拼接、变速、加水印、加字幕、转格式、压缩、封面提取、片段截取等常用操作。

工具兼容主流音视频与图片格式，处理速度快、资源占用低；所有操作在本地完成，不上传文件、不收集隐私信息，可显著提升内容制作与素材处理效率。

（二）性能

系统运行稳定，能够满足日常批量处理业务需求。

三、运行环境

（一）硬件设备：CPU i5 四核及以上；内存 8GB 及以上；硬盘可用空间 50GB 及以上。

（二）支持软件：Windows Server 2012、Windows 10；.NET Framework 3.5。

第 3 页

四、操作说明

（1）【主界面与文件导入】主窗口布局

截图展示了典型主窗口结构：左侧素材列表，右侧参数功能区（如画面调整/去水印/加水印/裁剪/变速/文本/背景音），底部为输出路径与开始处理区域。

  1. 启动软件后，确认左上角为“导入/移除/清空”素材操作区。
  2. 在右侧顶部切换功能标签，优先按“画面调整 → 去水印 → 加水印”等顺序配置。
  3. 在“画面微调（随机微调）”中可看到亮度、对比度、饱和度、锐化、降噪参数。
  4. 继续按需设置“宫格分屏”“分辨率调整”等功能开关。
  5. 最后在底部设置输出位置并点击“开始处理”。
第 4 页

（2）【主界面与文件导入】添加视频与目录导入

“导入”按钮支持下拉选择“导入文件”或“导入文件夹”，同时画布区域也提供“导入文件 / 导入文件夹”快捷入口。

  1. 点击左上角“导入”按钮，展开下拉菜单。
  2. 选择“导入文件”时，可一次选择多个视频文件。
  3. 选择“导入文件夹”时，适合批量导入同目录素材。
  4. 导入完成后，左侧列表会显示文件条目与状态。
  5. 如导入错误，可使用“移除”或“清空”重新整理任务列表。
第 5 页

（3）【核心处理能力】去水印功能

截图展示了去水印区域选择窗口：中间为可拖拽选区，底部有时间轴和“当前选区”坐标信息，适用于定位静态或阶段性水印。

  1. 进入“去水印”标签并启用功能后，点击“选区”。
  2. 在弹窗中拖动蓝色框体，覆盖目标水印位置。
  3. 拖动底部时间轴切换到有水印的典型帧进行校准。
  4. 查看底部“当前选区（原始视频坐标）”参数是否合理。
  5. 确认后点击“确认”，返回主界面继续处理。
第 6 页

（4）【核心处理能力】添加水印功能

截图为“手动定位水印位置”窗口：左侧视频画布用于拖拽定位，右侧“水印控制”包含快捷定位、文字设置、效果设置等参数。

  1. 进入“加水印”标签并打开手动定位窗口。
  2. 先在右侧“快捷定位”中选择大致方向，再微调位置。
  3. 在“文字设置”中填写文本内容，配置字体样式、字体大小、不透明度。
  4. 在“效果设置”中调整旋转角度等视觉参数。
  5. 点击“确定”保存位置与样式，返回主界面进行预览。
第 7 页

（5）【核心处理能力】裁剪功能（区域设置）

截图为“设置裁切区域”窗口：蓝色框表示保留画面，外围灰暗区域将被裁掉；底部会实时显示“边距”和“裁切后分辨率”。

  1. 进入“裁剪”标签并打开“设置裁切区域”。
  2. 拖动选区边缘或角点，确定最终保留画面范围。
  3. 观察网格辅助线，确保主体内容位于安全区域内。
  4. 查看底部“边距/裁切后分辨率”是否符合目标平台要求。
  5. 点击“确定”保存裁剪参数。
第 8 页

（6）【核心处理能力】变速功能

“变速”页支持基础倍速区间、最短时长限制、分段变速和音频变调等参数，可用于批量统一节奏。

  1. 切换到“变速”标签并打开“音视频变速”开关。
  2. 设置“变速倍数”范围（示例中为 1.00 ~ 1.05）。
  3. 按需启用“最短时长限制”，避免短视频被过度压缩。
  4. 按需启用“分段变速”，设置每段时长实现节奏变化。
  5. 若需修正音色，勾选“音频处理：启用变调”，再点击“预览效果”。
第 9 页

（7）【增强处理能力】文字轨道与字幕来源

截图展示“文字设置 - 文本1”弹窗，支持“文件名模式、文件夹模式、文本模式”三种来源，并提供位置与动画参数配置区。

  1. 进入“文本”标签，打开“文字设置 - 文本1”。
  2. 选择文本来源模式：文件名模式、文件夹模式或文本模式。
  3. 若使用文件夹模式，点击“浏览”选择文本文件来源目录。
  4. 若使用文本模式，直接在输入框填写文本内容。
  5. 完成“位置与边距设置”后，点击“预览效果”并保存。
第 10 页

（8）【增强处理能力】背景音与画面色调调整

背景音页面支持音频文件导入、音量、淡入淡出、延迟和循环策略；画面调整支持“色调设置”弹窗进行 Gamma、RGB 通道和色温范围调节。

  1. 在“背景音”标签开启背景音开关，点击“导入”选择音频文件。
  2. 设置“背景音量”，并按需勾选“淡入淡出”“延迟”“循环播放”“随机应用”。
  3. 在“原音处理”中按需调整原音音量和原音淡入淡出策略。
  4. 回到“画面调整”点击“色调调节”，打开色调设置窗口。
  5. 调整 Gamma、R/G/B 和色温范围后点击“预览效果”确认。

第 11 页

（9）【预览、执行与结果检查】预览效果

从截图可见，主功能卡片和参数弹窗均提供“预览效果”按钮。建议每次改动关键参数后先预览，确认再批处理。

  1. 在对应功能页点击“预览效果”。
  2. 优先检查裁剪边界、水印位置、文本可读性和音画同步。
  3. 如存在偏移或过度处理，回到参数区微调后再次预览。
  4. 通过预览后，再复制参数到整批视频执行。
  5. 建议保留一组稳定参数作为模板，下次直接复用。
第 12 页

（10）【预览、执行与结果检查】批量执行与状态查看

主界面底部包含输出位置、浏览按钮、进度条和“开始处理”。执行后可结合状态列与处理记录确认任务结果。

  1. 确认输出目录和关键参数后点击“开始处理”。
  2. 在底部进度条观察处理进度（如“0% - 未开始处理”会实时变化）。
  3. 在左侧列表查看单条视频“状态”列变化。
  4. 在“处理记录”中检查关键日志与异常提示。
  5. 对失败素材修正参数后再次执行该批次。
  6. 任务结束后点击“浏览”打开输出目录核验文件。
第 13 页

（11）【预览、执行与结果检查】选项与语言设置

截图中的“选项”窗口当前位于“转换”页，可配置输出格式、同名文件处理策略、文件名去除规则和并行任务数。

  1. 点击底部“选项”按钮，打开配置窗口。
  2. 在“目标文件格式”中选择 `Mp4` 或“源格式”。
  3. 在“若目标文件已存在”中选择“重命名”或“覆盖”。
  4. 按需启用“文件名去除”（支持关键词与正则）。
  5. 设置“并行任务数”后点击“确定”保存。
