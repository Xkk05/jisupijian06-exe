# 去头尾与变速功能测试计划

## 测试环境
- 准备测试视频：时长至少60秒，包含音频
- 确保 FFmpeg 可用

## 测试用例

### 一、去头尾功能测试

#### 1. 去头尾模式
**操作步骤：**
1. 勾选"视频长度裁剪"
2. 选择"去头尾"模式（默认）
3. 设置头=3秒，尾=5秒
4. 处理视频

**预期结果：**
- 输出视频时长 = 原视频时长 - 3 - 5
- 视频从第3秒开始，在倒数第5秒结束
- FFmpeg 命令包含 `-ss 3` 和 `-t [计算的时长]`

#### 2. 截取模式
**操作步骤：**
1. 勾选"视频长度裁剪"
2. 选择"截取"模式
3. 设置开始=10秒，秒长=20秒
4. 处理视频

**预期结果：**
- 输出视频时长 = 20秒
- 视频从第10秒开始播放
- FFmpeg 命令包含 `-ss 10` 和 `-t 20`

### 二、变速功能测试

#### 3. 固定变速（不变调）
**操作步骤：**
1. 勾选"音视频变速"
2. 设置变速倍数=1.5
3. 不勾选"变调"
4. 处理视频

**预期结果：**
- 输出视频时长 = 原时长 / 1.5
- 画面加速，音调不变
- FFmpeg 命令包含 `setpts=0.6667*PTS` 和 `atempo=1.5`

#### 4. 固定变速（变调）
**操作步骤：**
1. 勾选"音视频变速"
2. 设置变速倍数=2.0
3. 勾选"变调"
4. 处理视频

**预期结果：**
- 输出视频时长 = 原时长 / 2.0
- 画面加速，音调升高（像快进）
- FFmpeg 命令包含 `setpts=0.5*PTS` 和 `asetrate=88200,aresample=44100`

#### 5. 最短时长保护
**操作步骤：**
1. 使用20秒的测试视频
2. 勾选"音视频变速"，设置倍数=4.0
3. 勾选"最短时长"，设置10秒
4. 处理视频

**预期结果：**
- 原本输出 20/4=5秒，但因最短时长保护
- 实际速度自动调整为 20/10=2.0
- 输出视频时长 = 10秒
- 控制台输出速度调整提示

#### 6. 分段变速（不变调）
**操作步骤：**
1. 使用60秒测试视频
2. 勾选"音视频变速"
3. 勾选"分段变速 每"，设置10秒
4. 不勾选"变调"
5. 处理视频

**预期结果：**
- 视频被切分为6段（0-10, 10-20, ..., 50-60）
- 每段随机速度0.5-4.0
- 总时长为各段时长/速度之和
- FFmpeg 命令包含复杂的 filter_complex（trim+setpts+concat）
- 音频使用 atempo 级联（如速度>2需要多次atempo）

#### 7. 分段变速 + 最短时长保护
**操作步骤：**
1. 使用30秒测试视频
2. 勾选"音视频变速"
3. 勾选"分段变速 每"，设置10秒
4. 勾选"最短时长"，设置25秒
5. 处理视频

**预期结果：**
- 如果随机速度导致总时长<25秒
- 自动对所有段速度进行缩放
- 最终输出 ≥ 25秒
- 控制台输出"分段变速保护"提示

### 三、组合功能测试

#### 8. 去头尾 + 固定变速
**操作步骤：**
1. 勾选"视频长度裁剪"，去头3秒、去尾3秒
2. 勾选"音视频变速"，设置倍数=1.5
3. 处理视频

**预期结果：**
- 先裁剪，后变速
- 输出时长 = (原时长 - 6) / 1.5
- FFmpeg 命令：`-ss 3 -t [裁剪后时长]` 在前，变速滤镜在后

#### 9. 变速 + 加水印
**操作步骤：**
1. 勾选"音视频变速"，倍数=2.0
2. 勾选"加水印"，添加图片水印
3. 处理视频

**预期结果：**
- 视频加速且带水印
- 水印正常显示，不受变速影响
- 滤镜顺序：基础滤镜 → 变速 → 水印

#### 10. 去头尾 + 分段变速
**操作步骤：**
1. 勾选"视频长度裁剪"，截取10-40秒
2. 勾选"音视频变速"，分段变速每10秒
3. 处理视频

**预期结果：**
- 先截取30秒片段
- 然后分3段变速
- 分段基于截取后的视频（0-10, 10-20, 20-30）

## 已知限制

1. **分段变速与其他滤镜**：当前分段变速走独立路径，不支持同时使用其他复杂滤镜（如去水印、裁剪等）。如需同时使用，请先应用其他滤镜，再对结果进行分段变速。

2. **极端速度值**：
   - 速度 >4.0 或 <0.5 会被夹紧
   - 音频 atempo 单次限制 0.5-2.0，需要级联

3. **精度损失**：分段变速涉及多次编码，可能有轻微质量损失。

## 回归测试

确保以下功能未受影响：
- ✓ 去水印（FFmpeg/AI方法）
- ✓ 加水印（图片/文字）
- ✓ 裁剪
- ✓ 旋转翻转
- ✓ 画面调整
- ✓ 帧率调整

## 故障排除

**问题1：分段变速后音频不同步**
- 检查是否所有段都正确应用了 asetpts=PTS-STARTPTS
- 确认 concat 参数 v=1:a=1

**问题2：变调后音质下降**
- 这是正常的，asetrate 会改变采样率
- 可尝试不变调模式

**问题3：最短时长保护未生效**
- 确认勾选了"最短时长"复选框
- 检查控制台是否有速度调整提示
