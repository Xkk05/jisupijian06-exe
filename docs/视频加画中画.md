**一、画中画功能总控（顶部第一行）**

**左侧：功能开关**

复选框 + 文字「视频画中画」（总控规则：勾选后下方所有画中画相关功能 / 参数可操作；未勾选则全部呈灰色不可选）。

**右侧：预览功能**

「预览」按钮（用突出颜色如蓝色显示），点击可实时查看当前配置的画中画效果，无需跳转页面。

**二、核心模式选择（总控行下方，单选互斥）**

两种模式前各加单选框，用户仅能选择其一，模式对应的参数组件随选择状态切换（选中则亮显可操作，未选中则灰色不可编辑）：

1. **「视频模式」**（无额外背景，以自身视频为背景）

附加参数（同行排列）：

「上下」标签 + 文本框（仅支持数字）：控制视频上下边距（例：填 50 = 视频上边距、下边距均距背景边缘 50 单位）。

「左右」标签 + 文本框（仅支持数字）：控制视频左右边距（逻辑同上）。

通用功能（与模式无关，同行右侧排列）：

复选框 + 文字「背景虚化」+ 文本框 + 上下三角形箭头按钮 + 单位标识

文本框：默认值 1，支持手动输入 0-1 的数值，也可通过箭头按钮微调（点击一次 ±0.01）。

规则：数值越大，背景虚化程度越高；无需选中任何模式即可勾选操作。

**2. 「背景模式」**（以外部图片 / 视频作为背景）

附加组件（同行从左到右排列）：

文本框：用于展示选中的背景文件路径（默认空白，选择文件后自动填充）。

「选择文件」按钮：点击弹出本地文件选择框，支持导入图片 / 视频文件。

模式切换图标：位于「选择文件」按钮右侧，点击可在「文件模式」和「目录模式」间切换。

视觉：两种模式对应不同图标（例：文件模式 = 文件图标，目录模式 = 文件夹图标）。

提示：鼠标悬浮或切换时显示tooltip：

文件模式：「选取具体的背景文件」

目录模式：「设置背景资源文件夹，顺序或随机 (设置中设定) 选取画中画背景」

「设置」按钮：用差异化颜色（如橙色）显示，点击后根据当前选中的模式，打开对应的样式设置窗口。

**三、「设置」按钮跳转窗口**（分两种模式）

**（一）选中「视频模式」时：打开「画中画之视频模式 - 样式设置」窗口**

窗口顶部显示标题，下方按功能分区排列参数，最后一行是操作按钮：

**1. 位置偏移设置**（第一行）

「上下偏移」标签 + 文本框 + 上下箭头按钮：

支持手动输入数字，或点击箭头微调（±1）；正数 = 视频向下偏移，负数 = 视频向上偏移（例：100 = 上边距下移 100，-100 = 下边距上移 100）。

「左右偏移」标签 + 文本框 + 上下箭头按钮：

逻辑同上；正数 = 视频向右偏移，负数 = 视频向左偏移（例：100 = 左边距右移 100，-100 = 右边距左移 100）。

**2. 入场动画设置**（第二行）

「入场动画」标签 + 下拉框：

选项：无、左边、右边、上边、下边、左右、上下。

功能：控制画中画视频出现方式（例：左边 = 从左侧水平移入，左右 = 从左右两侧开合聚拢）。

同行右侧参数（从左到右）：

「延时」标签 + 文本框 + 上下箭头按钮：单位秒，支持手动输入或微调（±0.1），控制动画延迟出现时间（例：5=5 秒后出现）。

「持续」标签 + 文本框 + 上下箭头按钮：单位秒，支持手动输入或微调（±0.1），控制动画持续时长（例：5 = 动画 5 秒内完成）。

**3. 窗口操作按钮**（最后一行）

从左到右：「重置」→「确定」→「取消」

重置：清空所有参数，恢复默认状态。

确定：保存当前设置，关闭窗口。

取消：不保存设置，直接关闭窗口。

**（二）选中「背景模式」时：打开「画中画之背景模式 - 样式设置」窗口**

窗口顶部显示标题，下方按功能分区排列参数，最后一行是操作按钮：

**1. 视频位置设置（第一 - 三行，单选互斥）**

**第一行：「居中」单选框 + 附加参数**

「边距」标签 + 文本框 + 上下箭头按钮：支持手动输入或微调（±1），控制视频上下边距（例：100 = 上下边距均为 100，-100 = 拉伸视频高度实现负边距）。

「偏移」标签 + 文本框 + 上下箭头按钮：支持手动输入或微调（±1），控制水平偏移（例：200 = 以中心为起点右移 200，-200 = 左移 200）。

同行右侧：「应用背景资源分辨率」复选框（仅「居中」选中时可操作，否则灰色）

右侧小问号提示（点击查看）：「此项决定是否以画中画背景或视频分辨率做缩放基础，不勾，则视频大小保持不变，改变背景资源尺寸。勾选，则生成的视频尺寸同背景资源，对视频进行缩放。小提示：视频位置非居中模式下，即使用背景资源分辨率。」

**第二行：四角位置选项（单选互斥）「左上」「右上」「左下」「右下」单选框 + 右侧小问号**提示（点击查看）：「非居中模式，视频可居于背景之四角。其中短距为视频距角边的距离：长距为相对角边之对角所在边的最短距离。理解上有些困难，可预览以查看效果。」

**第三行：边缘对齐选项（单选互斥）「左或上」「右或下」单选框 + 右侧小问号提示（点击查看）**：「它们决定视频是否与背景边缘对齐，根据分辨率比率决定停靠位置（例：左或上 = 视频与背景左侧 / 上侧对齐）。」

**2. 四角位置专属参数（第四行）**

「短距」「长距」标签 + 对应文本框（仅选中「左上 / 右上 / 左下 / 右下」时可编辑，否则灰色）：支持手动输入数字，控制视频与背景角边的距离。

**3. 视频基础设置（第五行）**

「视频画面始于（）帧」：括号替换为文本框 + 上下箭头按钮，支持手动输入或微调（±1），控制视频起始帧。

「透明度」标签 + 文本框 + 上下箭头按钮：默认值 1，支持输入 / 微调（±0.01），范围 0.01-1；数值越小越透明。

「羽化」复选框 + 文本框 + 上下箭头按钮：支持输入 / 微调（±0.01），范围 0.01-1；数值越大，视频边缘羽化越明显。

右侧小问号提示（点击查看）：「视频边缘羽化显示。若勾选 [视频背景去除]，此功能将不可用」。

**4. 背景与视频适配设置（第六 - 七行）**

第六行：「时长置以短者」复选框 + 右侧小问号提示（点击查看）：「若背景资源为视频且其长度小于主视频，则以其时长为准」。

第七行：「视频背景去除」复选框 + 右侧小问号提示（点击查看）：「此功能可以去除视频中的纯色背景，如抠蓝幕绿幕之类」。

**5. 背景去除方式（第八 - 九行，单选互斥，仅「视频背景去除」勾选后可操作）**

第八行：「获取视频背景色」单选框 + 附加参数

「x」「y」标签 + 对应文本框 + 上下箭头按钮（微调 ±1）：通过坐标定位取色。

「时间」标签 + 文本框 + 上下箭头按钮（微调 ±0.1）：单位秒，控制取色的时间点。

第九行：「指定背景色」单选框 + 颜色下拉框：点击下拉框选择目标颜色（例：绿色 = 去除视频中所有绿色背景）。

**6. 窗口操作按钮（最后一行）**

从左到右：「重置」→「预览」→「确定」→「取消」

重置：清空所有参数，恢复默认状态。

预览：突出颜色显示，点击查看当前设置的效果。

确定：保存设置，关闭窗口。

取消：不保存设置，直接关闭窗口。

**四、关键逻辑梳理（避免混淆）**

总控开关优先级：「视频画中画」复选框未勾选时，所有模式、参数、按钮均不可操作。

模式与组件联动：「视频模式」仅显示上下 / 左右边距参数，「背景模式」仅显示文件选择相关组件；参数组件随模式选中状态亮显 / 灰色。

窗口跳转规则：「设置」按钮仅在选中某一模式后可点击，跳转窗口与当前模式严格对应。

特殊参数限制：「应用背景资源分辨率」「短距 / 长距」「背景去除方式」等，需满足前置条件（如选中对应单选框）才可操作。
