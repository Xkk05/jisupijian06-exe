## ⚠️ UI显示美观的关键配置

### 必须设置（90%的UI问题来源）

**1. 系统DPI缩放设置为100%**
```
右键桌面 → 显示设置 → 缩放与布局 → 100%
```

**2. 高DPI兼容性设置**（如果必须用125%缩放）
```
右键启动文件 → 属性 → 兼容性 → 更改高DPI设置
✅ 勾选"替代高DPI缩放行为"
选择"系统（增强）"
```

**3. 启用ClearType字体**
```
控制面板 → 字体 → 调整ClearType文本 → 启用
```

### 自动配置（已集成在代码中）

程序启动时会自动设置：
- ✅ 高DPI支持
- ✅ 抗锯齿字体渲染
- ✅ 微软雅黑默认字体
- ✅ 最佳UI缩放因子

## 🛠️ 常见问题解决

### UI显示模糊

**症状**：界面字体模糊、控件边缘不清晰

**解决方案**：
1. 系统设置 → 显示 → 缩放100%
2. 右键启动文件 → 兼容性 → 高DPI设置 → 系统（增强）
3. 重启程序

### 控件尺寸异常

**症状**：按钮过大/过小、布局错乱

**解决方案**：
```bash
pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip
pip install PyQt6==6.6.1 PyQt6-Qt6==6.6.1 PyQt6-sip==13.6.0
```

### 中文显示为方块

**症状**：界面中文字符显示为□□□

**解决方案**：
1. 检查是否安装微软雅黑字体（Windows系统自带）
2. 运行验证脚本检查字体

### 缺少依赖包

**症状**：启动报错"No module named 'xxx'"

**解决方案**：
```bash
# 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 重新安装依赖
pip install -r requirements.txt
```

### FFmpeg错误

**症状**：视频处理失败，提示FFmpeg错误

**解决方案**：
1. 确保 `ffmpeg\ffmpeg.exe` 文件存在
2. 检查文件权限
3. 尝试手动运行FFmpeg测试

## 📌 重要提示

### ⚠️ 关键点

1. **UI显示问题90%来源于系统DPI缩放**
   - 必须设置为100%
   - 或配置高DPI兼容性

2. **PyQt6版本必须是6.6.1**
   - 不要升级
   - 其他版本可能导致UI异常

3. **虚拟环境建议重新创建**
   - 迁移到新电脑时删除旧的venv
   - 重新运行 `python -m venv venv`

4. **微软雅黑字体是必需的**
   - Windows系统通常自带
   - 确保未被删除或禁用

### ✅ 最佳实践

- 使用虚拟环境隔离依赖
- 定期运行验证脚本
- 保持依赖版本一致
- 遇到问题先检查DPI设置
