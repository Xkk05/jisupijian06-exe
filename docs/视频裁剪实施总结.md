# 视频裁剪功能实施总结

## 实施概述

按照 `docs/视频裁剪.md` 规范，完成了视频裁剪功能的完整实现，包括UI重构、裁切区域选取页、处理链路统一。

## 实施内容

### 1. 配置结构统一

**文件：** 
- `processor/detailed_video_processing_config.py`
- `processor/batch_advanced_config.py`
- `config/config_manager.py`

**改动：** 统一裁剪配置为三种模式：
```python
- mode: "像素" | "中间" | "百分比"
- 像素模式: pixel_top, pixel_bottom, pixel_left, pixel_right
- 中间模式: aspect_ratio ("1:1", "16:9", "9:16", "4:3", "3:4")
- 百分比模式: percent_value (1-100), percent_crop_mode (11种位置)
- random_crop: 随机裁剪开关
```

### 2. UI重构

**文件：** `ui/batch_video_processor_window.py`

**改动：**
- **顶部控制行**：总开关复选框 + 预览按钮（蓝色）+ 选取按钮（橙色）
- **裁剪方法选择区**：
  - 像素方法：单选框 + 上/下/左/右四个SpinBox
  - 中间方法：单选框 + 裁剪比例下拉框（5个选项）
  - 百分比方法：单选框 + 百分比输入 + 画面裁剪模式下拉框（12个选项）
- **启用规则**：
  - 总开关关闭时，所有裁剪控件禁用
  - 选取按钮仅在"像素"模式下启用
  - 三种方法单选互斥

**事件处理函数：**
- `_on_crop_enabled_changed`: 总开关状态变化
- `_on_crop_method_changed`: 裁剪方法切换
- `_on_crop_preview`: 预览功能（待实现）
- `_on_crop_select`: 打开裁切区域选取页
- `_get_crop_mode`: 获取当前选中的裁剪模式

### 3. 裁切区域选取页

**文件：** `ui/crop_region_selector.py`（新建）

**功能：**
- **视频预览**：加载视频首帧，自动缩放适配窗口
- **交互裁切框**：
  - 可拖拽四条边（上、下、左、右）
  - 可拖拽四个角点（同时调整相邻两边）
  - 鼠标悬停时改变光标样式
  - 半透明蒙版标识裁切区域外
- **信息提示栏**：显示视频分辨率和时长
- **实时参数提示栏**：
  - 边距：上、下、左、右（像素值）
  - 裁切后分辨率：宽×高
  - 每次拖拽实时更新
- **确定/取消按钮**：返回裁切边距给主界面

### 4. 处理链路接入

**文件：** 
- `processor/batch_params_processor.py`
- `processor/ffmpeg_builder.py`（已支持）

**改动：** 更新 `_build_crop_filter` 方法，统一支持三种模式：

**像素模式：**
```python
crop=iw-{left+right}:ih-{top+bottom}:{left}:{top}
```

**中间模式：**
```python
crop='if(gt(a,{aspect_ratio}),ih*{aspect_ratio},iw)':'if(gt(a,{aspect_ratio}),ih,iw/{aspect_ratio})':(iw-ow)/2:(ih-oh)/2
```

**百分比模式：**
- 四边：均匀裁剪
- 左上/右上/左下/右下：保留对应象限
- 上边/下边/左边/右边：保留对应边
- 上下/左右：裁剪两边，保留中间
- 随机：随机位置裁剪

### 5. 配置传递

**流程：**
1. UI `collect_config()` → 输出字典格式配置
2. `BatchParamsProcessor` → 接收字典配置
3. `_build_crop_filter()` → 根据mode生成FFmpeg crop过滤器
4. FFmpeg执行裁剪

## 技术要点

### 1. 坐标转换
- 视频坐标系 ↔ 控件坐标系
- 考虑缩放因子和居中偏移

### 2. 边距计算
- 像素模式：直接使用上下左右边距
- 中间模式：根据宽高比计算居中裁切区域
- 百分比模式：根据百分比和位置计算裁切区域

### 3. FFmpeg表达式
- 使用 `iw`, `ih` 表示输入宽高
- 使用 `ow`, `oh` 表示输出宽高
- 使用 `a` 表示宽高比
- 使用 `if(condition, true_val, false_val)` 条件表达式
- 使用 `max(1, ...)` 确保尺寸至少为1

### 4. UI交互优化
- 鼠标跟踪启用（setMouseTracking）
- 光标样式动态变化
- 半透明蒙版视觉反馈
- 实时参数更新信号
