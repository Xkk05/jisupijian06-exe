## 📝 详细技术分析

### 1. ✅ 已完整实现的功能

这些功能的前后端逻辑已经闭环，代码逻辑完整。

#### 去水印 (Remove Watermark)

* **前端**: `remove_watermark_tab.py` 提供了区域选择、模式设置等控件。
* **后端**: 
  * `BatchParamsProcessor._build_delogo_filter`: 构建 FFmpeg `delogo` 滤镜字符串。
  * `process_video` -> `_process_watermark_removal`: 包含专门的预处理逻辑，支持多区域处理。

#### 加水印 (Add Watermark)

* **前端**: `add_watermark_tab.py` 支持图片和文字设置，包含位置、大小、透明度等。
* **后端**: 
  * `_build_image_watermark_graph`: 实现了复杂的图片水印逻辑（支持 GIF、缩放、旋转、动态位置）。
  * `_build_drawtext_filter`: 实现了文字水印，支持字体、边框、阴影等。

#### 裁剪 (Crop)

* **前端**: `crop_tab.py` 提供三种模式（像素/中间/百分比），含可视化裁剪区域选择器。
* **后端**: 
  * `_build_crop_filter`: 已实现核心逻辑，支持固定裁剪 (`crop=w:h:x:y`) 和随机裁剪。
  * `_build_resolution_filter`: 处理分辨率调整。

#### 画中画 (Picture-in-Picture)

* **前端**: `pip_tab.py` 支持视频模式和背景模式，含位置、动画、虚化等设置。
* **后端**: 
  * `_build_pip_graph`: 使用 `overlay` 滤镜实现画中画效果，支持位置偏移、透明度、羽化等。
  * 支持背景视频/图片作为底图，主视频叠加在上面。

#### 去头尾 (Trim)

* **前端**: `trim_tab.py` 支持去头尾模式和截取模式。
* **后端**: 
  * 在构建 FFmpeg 命令时添加 `-ss` 和 `-t` 参数实现裁剪。
  * 支持头秒数+尾秒数模式，以及开始时间+时长模式。

#### 加头尾 (Intro/Outro)

* **前端**: `add_intro_outro_tab.py` 支持片头、片尾、边框设置。
* **后端**: 
  * `_build_head_tail_concat_command`: 使用 concat demuxer 拼接多个视频片段。
  * `_build_border_overlay_filter`: 实现边框叠加效果。
  * 支持文件模式和目录模式（随机/顺序选择）。

#### 变速 (Speed Adjustment)

* **前端**: `speed_tab.py` 支持固定变速和分段变速，含变调、最短时长保护等。
* **后端**: 
  * `_build_speed_filter`: 使用 `setpts` 滤镜实现视频变速。
  * `_build_segment_speed_command`: 实现分段变速，每段可设置不同速度。
  * 支持音频变速（`atempo`）和变调（`asetrate`+`aresample`）。

#### 背景音 (Background Music)

* **前端**: `audio_tab.py` 支持背景音乐文件选择、音量调节、淡入淡出、延迟等。
* **后端**: 
  * `_add_background_audio_input`: 添加背景音乐输入。
  * `_build_background_audio_mix_filter`: 使用 `amix` 滤镜混合原声和背景音。
  * 支持音量调节、淡入淡出、延迟、循环播放。

### 2. ⚠️ 部分实现的功能

#### 文本 (Text Overlay)

* **状态**: ⚠️ **功能受限**
* **前端**: `text_tab.py` 提供了三个文本输入框。
* **后端**: 
  * `_build_text_filter`: 逻辑较为简单，部分参数硬编码：
    * 字体大小: `24` (部分硬编码)
    * 字体颜色: `white` (部分硬编码)
    * 位置: `x=10`, `y=10+i*30` (固定左上角垂直排列)
  * **改进空间**: 可复用 `_build_drawtext_filter` (用于水印模块) 的强大功能，支持更多自定义选项。
