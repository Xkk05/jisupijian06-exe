**一、整体布局规则**

功能模块以 横向排列、垂直分层 为核心布局逻辑，共分为 3 行独立功能区（分别对应 **“片头”“片尾”“边框”**），片头用于给视频最前面添加一段视频，片尾用于给视频最后面添加一段视频，边框用于给视频添加图片背景（仅支持导入 png、jpg、gif 格式文件）。每行均遵循 “启用控制→路径展示→功能配置→附加操作” 的从左到右排列顺序，所有元素尽量横向对齐、间距统一，视觉上规整清晰。核心交互原则为：仅勾选功能前的复选框，该功能对应的后续配置项才会激活可用；未勾选时，所有关联元素均呈灰色不可操作状态。

**二、分功能布局与交互逻辑**

**（一）第一行：片头功能**

从左至右依次排列以下元素，交互联动紧密：

**启用控制：**「□ 片头」（复选框 + 黑色功能文字），作为该功能的总开关。未勾选时，右侧所有元素均不可点击；勾选后，立即激活后续所有配置项。

**路径展示：**一个默认空白的文本框（灰色边框），仅用于展示选中的文件或目录路径，不可手动输入内容。当后续选择文件 / 目录后，文本框会自动覆盖原有内容，填充最新的完整本地路径（如 “D:\ 素材 \ 片头 \ 开场.mp4”）。

**文件选择：**文本框右侧的「选择文件」按钮，点击后弹出本地文件选择框，仅支持导入视频格式文件（如 mp4、mov、avi 等）。按钮的可选类型会随后续模式切换同步变化：当前为「文件模式」时，仅能选择单个视频文件；切换为「目录模式」时，仅能选择文件夹。

**模式切换：**「选择文件」按钮右侧的图标（默认显示 “文件图标”），点击可在「文件模式」和「目录模式」间切换，切换后图标变为对应样式（目录模式显示 “文件夹图标”）。鼠标悬浮在图标上时，会显示当前模式提示（如 “当前为文件模式，点击切换至目录模式”），明确告知用户当前状态。

**随机应用：**模式切换图标右侧的「□ 随机应用」（复选框 + 黑色文字），该选项仅在「目录模式」下激活可用：未勾选时，系统按目录内文件的系统排序（名称或创建时间）依次选取片头；勾选后，每次从目录内所有视频文件中随机抽取 1 个作为片头。若处于「文件模式」，该复选框会自动呈灰色不可选状态，无论之前是否勾选均失效。

**（二）第二行：片尾功能**

布局与交互逻辑和「片头功能」完全一致，仅功能名称改为 “片尾”，核心规则如下：

启用控制为「□ 片尾」，勾选后激活后续配置；

「选择文件」按钮仅支持导入视频格式文件，模式切换联动文件 / 目录选择权限；

「随机应用」复选框仅在「目录模式」下可用，控制片尾文件的顺序选取或随机选取，「文件模式」下不可操作。

**（三）第三行：边框功能**

从左至右依次排列以下元素，新增专属功能入口与预览交互：

**启用控制**：「□ 边框」（复选框 + 黑色功能文字），勾选后激活右侧所有配置项，未勾选时右侧元素均不可用。

**路径展示**：默认空白的文本框（灰色边框），仅展示选中的边框文件或目录路径，不可手动输入，选择文件 / 目录后自动填充最新路径。

**文件选择**：「选择文件」按钮（样式同前），点击弹出本地文件选择框，仅支持导入 png、jpg、gif 三种格式的边框背景文件。模式切换会联动选择类型：「文件模式」下选单个边框文件，「目录模式」下选存放边框文件的文件夹。

**模式切换**：「选择文件」按钮右侧的图标（默认文件图标），点击切换「文件模式」/「目录模式」，悬浮时显示模式提示。「文件模式」下固定使用所选单个边框文件；「目录模式」下无需额外设置，系统默认从目录内随机选取 1 个边框文件应用。

**透明＆边距**：模式切换图标右侧的蓝色文字（颜色区别于其他元素，明确为功能入口），仅在勾选「边框」复选框后可点击。点击后弹出独立的「边框样式」设置窗口，窗口悬浮于原功能模块上方，同时原模块背景置灰不可操作，确保用户聚焦于窗口内设置。

**预览功能**：「透明＆边距」右侧的橙色文字（颜色区别于其他元素，与蓝色入口区分），仅在满足两个条件时激活：① 勾选「边框」复选框；② 已成功选择边框文件或目录。点击后弹出预览窗口，展示视频添加当前边框（含已配置的透明、边距、背景色消除效果）后的完整画面，支持播放 / 暂停操作，预览完成后可关闭窗口返回原设置页。

**三、「边框样式」窗口布局与交互逻辑**

该窗口为独立弹窗，内部按 “标题→功能设置区→操作按钮区” 垂直排列，所有元素左对齐，间距统一：

**窗口标题：**顶部居中显示「边框样式」黑色粗体文字，明确窗口功能，不可编辑。

**透明功能设置：**标题下方第一行，从左至右为「□ 透明」（复选框 + 黑色文字）+「透明度」标签 + 文本框 + 上下箭头按钮（文本框默认显示 “1”）。交互规则：

未勾选「透明」复选框：右侧文本框及上下箭头呈灰色不可操作；

勾选后激活：支持手动输入 0.01-1 之间的两位小数（输入无效值如 0、1.01 时，文本框边框变红提示错误），或点击箭头微调（上箭头 + 0.01，下箭头 - 0.01），触达 0.01 或 1 的边界时，对应箭头呈灰色不可点击，数值越小，边框背景越透明。

实时反馈：调整数值时，若已打开预览窗口，预览画面会同步更新边框透明度效果。

边距功能设置：透明功能下方一行，从左至右为「□ 边距」（复选框 + 黑色文字）+「x」标签 + 文本框 + 上下箭头 +「y」标签 + 文本框 + 上下箭头。

交互规则：未勾选「边距」复选框：所有边距参数元素不可操作；

勾选后激活：支持手动输入整数或箭头微调（±1），无数值上限（根据视频分辨率自适应显示）；

效果对应：x 轴控制视频左右与边框的距离，y 轴控制上下距离，调整时预览画面同步变化。

**背景色消除功能设置：**边距功能下方一行，从左至右为「□ 背景色消除」（复选框 + 黑色文字），勾选后激活下方两种互斥取色方法（单选框控制，选中一个则另一个自动取消）：

**第一种方法（下方第一行）：「○ 获取视频背景色」**（单选框 + 黑色文字）+「x」标签 + 文本框 + 箭头 +「y」标签 + 文本框 + 箭头 +「时间」标签 + 文本框 + 箭头。x/y 坐标用于定位视频画面取色点（微调 ±1，需在视频分辨率范围内），时间参数控制取色的视频帧（单位秒，微调 ±0.1，需在视频时长范围内），输入无效值时文本框变红提示；

**第二种方法（下方第二行）：「○ 指定背景色」**（单选框 + 黑色文字）+ 颜色下拉框（默认显示 “请选择颜色”）。点击下拉框弹出颜色面板（含常用色块 + 自定义色值输入），选择后下拉框显示所选颜色名称及色块（如 “绿色 #00FF00”），预览画面中对应颜色区域会实时消除。

**操作按钮区：**窗口底部横向排列三个灰色边框按钮，从左至右依次为「重置」「确定」「取消」，交互逻辑：

**「重置」：**点击后清空所有设置（取消所有复选框勾选，参数恢复默认值，文本框清空），窗口不关闭，可重新配置；

**「确定」：**点击后校验所有激活的参数，校验通过则保存设置并关闭窗口，返回原功能模块；校验失败（如存在无效值）则弹出提示框（如 “请输入有效的透明度数值”），窗口不关闭，需修正后重新点击；

**「取消」：**点击后不保存任何修改，直接关闭窗口返回原模块，窗口内所有临时调整失效。

四、核心交互规则总结

所有功能均遵循 “勾选启用→配置参数” 的流程，未启用时关联元素均不可操作，避免误触；

模式切换会联动后续选择权限与参数可用性（如片头 / 片尾的 “随机应用” 仅目录模式可用），逻辑闭环；

「边框样式」窗口内，功能勾选状态与参数操作权限强绑定，调整参数实时同步预览效果，直观反馈；

所有输入框均有有效性校验，通过颜色提示或弹窗告知错误，确保配置合规。
