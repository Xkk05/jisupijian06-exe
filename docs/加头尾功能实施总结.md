## 技术实现要点

### 视频拼接策略

使用 **Concat Demuxer** 方式：
- 创建临时txt文件列出所有片段
- 使用 `-f concat -safe 0` 读取文件列表
- 优点：可靠、兼容性好
- 缺点：需要统一格式（已处理）

### 边框处理

滤镜链结构：
```
movie=边框.png → scale=W:H → format=rgba 
→ chromakey (可选，背景消除) 
→ colorchannelmixer (透明度) 
→ overlay (叠加到视频)
```

### 文件选择逻辑

- **文件模式**: 直接使用指定文件
- **目录模式**: 
  - 随机选择：使用variant作为种子（可重复）
  - 顺序选择：按文件名排序，使用 `variant % len(files)`
