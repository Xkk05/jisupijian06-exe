## 3. 本轮新发现问题

### N-1 无音轨视频无法处理（高）

- 对 2 秒 H.264 无音轨 MP4 执行基础处理，命令构建直接出现 `AttributeError: 'NoneType' object has no attribute 'lower'`。
- 正式批处理会把该文件标记为失败，不会导致整个应用崩溃，但所有无音轨视频都会受影响。
- 原因是 `audio_codec_name` 为 `None`，兼容检查直接调用 `.lower()`。
- 位置：`utils/video_codec_checker.py:129`、`utils/video_codec_checker.py:217-233`。

### N-2 色调 RGB 参数大于 1.0 时正式处理失败（高）

- UI 允许红、绿、蓝输入 `0.0-10.0`；红色设为 `1.01` 时 FFmpeg 返回码 1。
- 错误：`Error setting option rs to value 1.01`。
- 内置 FFmpeg 的 `colorbalance rs/gs/bs` 有效范围是 `-1.0-1.0`，UI 范围与命令参数语义不一致。
- 位置：`ui/color_tone_dialog.py:53-67`、`processor/batch_params_processor.py:1086`。

### N-3 普通变速启用“变调”时 48kHz 音频不同步（中）

- 3 秒、48kHz 输入设置 0.75 倍速并启用变调，视频为 `4.000s`，音频为 `4.365s`，相差 `0.365s`。
- 同样倍率关闭变调时视频 `4.000s`、音频 `4.004s`，同步正常。
- 变调分支直接按固定 44.1kHz 执行 `asetrate`，没有先把 48kHz 输入统一重采样。
- 位置：`processor/batch_params_processor.py:1728-1729`。
