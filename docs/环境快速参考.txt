📋 系统要求
──────────────────────────────────────────────────────────────
  操作系统: Windows 10/11 (64位)
  Python版本: 3.8 - 3.11 (推荐 3.11)
  最低内存: 8GB RAM
  推荐内存: 16GB+ RAM

🎨 UI显示最佳配置（重要！）
──────────────────────────────────────────────────────────────
  ✅ 系统缩放: 100% (最佳)
  ✅ 分辨率: 1920x1080 或更高
  ✅ ClearType: 启用
  ✅ 字体: 微软雅黑（系统自带）

  【设置方法】
  1. 右键桌面 → 显示设置
  2. 缩放与布局 → 100%
  3. 如必须用125%，请设置高DPI兼容性

📦 核心依赖包版本（固定版本）
──────────────────────────────────────────────────────────────
  PyQt6==6.6.1              # UI框架（不要升级！）
  PyQt6-Qt6==6.6.1         # Qt底层
  PyQt6-sip==13.6.0        # Python绑定
  opencv-python==4.10.0.84 # 视频处理
  numpy==1.26.4            # 数值计算
  Pillow==10.4.0           # 图像处理

🚀 快速部署步骤（新电脑）
──────────────────────────────────────────────────────────────
  1. 复制整个项目文件夹到新电脑
  2. 确保Python 3.8+已安装
  3. 运行: 快速环境配置.bat
  4. 运行: python 验证环境.py
  5. 启动: 批量去水印.bat

📝 详细命令
──────────────────────────────────────────────────────────────
  # 创建虚拟环境
  python -m venv venv

  # 激活虚拟环境（PowerShell）
  .\venv\Scripts\Activate.ps1

  # 激活虚拟环境（CMD）
  .\venv\Scripts\activate.bat

  # 安装核心依赖
  pip install PyQt6==6.6.1 PyQt6-Qt6==6.6.1 PyQt6-sip==13.6.0

  # 安装所有依赖
  pip install -r requirements.txt

  # 验证环境
  python 验证环境.py

  # 启动程序
  .\批量去水印.bat

🔧 常见问题快速解决
──────────────────────────────────────────────────────────────
  问题1: UI字体模糊、发虚
  解决: 系统设置 → 显示 → 缩放100%
       或右键启动文件 → 兼容性 → 高DPI设置

  问题2: 控件尺寸异常
  解决: pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip
       pip install PyQt6==6.6.1 PyQt6-Qt6==6.6.1 PyQt6-sip==13.6.0

  问题3: 中文显示为方块
  解决: 安装微软雅黑字体（通常系统自带）

  问题4: 缺少依赖包
  解决: pip install -r requirements.txt

  问题5: FFmpeg错误
  解决: 确保 ffmpeg\ffmpeg.exe 存在
