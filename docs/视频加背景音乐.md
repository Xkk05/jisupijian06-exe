**背景音乐功能参数详细说明**

**一、功能总控（顶部第一行）**

**1.1 总控开关**

**组成：复选框 + 文字「背景音乐」**

控制规则：勾选后，下方所有背景音乐相关功能、参数解锁可操作；未勾选时，所有相关功能、参数均呈灰色禁用状态，无法编辑。

**1.2 音频路径展示与导入组件**

**路径文本框：**位于总控开关右侧，用于实时显示已导入音频文件或目录的本地完整路径，仅展示不支持手动输入，路径随导入操作自动更新。

**本地导入按钮：**紧邻路径文本框右侧，点击后弹出本地文件浏览器，支持根据当前模式选择单个音频文件或音频文件夹。

**模式切换图标：**位于导入按钮右侧，两种模式对应差异化图标（文件模式 = 单个文件图标，目录模式 = 文件夹图标）。

**交互提示：**鼠标悬浮或点击图标时，弹出 tooltip 提示 —— 文件模式显示「选取具体的音频文件」，目录模式显示「设置音频资源文件夹，按顺序调用文件」；点击图标可在两种模式间快速切换。

**二、核心参数配置（总控行下方，第二行）**

**2.1 背景音量调节**

**组成：「背景音量」标签 + 数值输入文本框 + 文本框两侧上下箭头按钮**

输入支持：支持手动输入数值，也可通过箭头按钮微调

调节规则：每点击一次上箭头，数值增加 0.1；点击一次下箭头，数值减少 0.1，数值无单位，按音量比例量化（建议取值范围 0-1）。

**2.2 淡入淡出效果设置**

**组成：复选框（启用开关） + 「淡入淡出」标签 + 数值输入文本框 + 文本框两侧上下箭头按钮 + 单位「秒」**

启用规则：仅勾选复选框后，该功能生效，调节控件可操作；未勾选时控件灰色无效。

输入支持：支持手动输入数值，或通过箭头按钮微调

调节规则：每点击一次箭头，数值增减 1，单位为秒，用于定义背景音乐淡入启动和淡出结束的过渡总时长。

**2.3 延迟播放设置**

**组成：复选框（启用开关） + 「延迟」标签 + 数值输入文本框 + 文本框两侧上下箭头按钮 + 单位「秒」**

启用规则：勾选复选框后功能生效，调节控件解锁；未勾选时控件禁用。

输入支持：支持手动输入数值，或通过箭头按钮微调

调节规则：每点击一次箭头，数值增减 1，单位为秒，用于设定从触发播放指令到背景音乐实际启动的间隔时间。

**三、扩展参数配置（第二行下方，第三行）**

**3.1 原音音量调节**

**组成：复选框（启用开关） + 「原音音量」标签 + 数值输入文本框 + 文本框两侧上下箭头按钮**

启用规则：勾选复选框后，可对原音音量进行调节；未勾选时控件灰色不可操作。

输入支持：支持手动输入数值，或通过箭头按钮微调

调节规则：每点击一次箭头，数值增减 0.1，无单位，按原音音量比例量化（建议取值范围 0-1）。

**3.2 原音淡入淡出同步设置**

**组成：复选框（启用开关） + 「原音亦淡入淡出」标签**

功能逻辑：无需额外数值配置，勾选后原音将自动同步「淡入淡出」参数设定的过渡时长，与背景音乐保持一致的淡入、淡出节奏。

**3.3 循环播放设置**

**组成：复选框（启用开关） + 「循环播放」标签**

功能逻辑：勾选后生效，当导入的音频文件时长不足以覆盖使用场景（如视频时长大于音频时长）时，系统自动重复循环该音频，直至场景结束。

**3.4 随机应用设置**

**组成：复选框（启用开关） + 「随机应用」标签**

启用限制：仅当音频导入模式为「目录模式」时，复选框解锁可勾选；若当前为「文件模式」，参数名称及复选框均呈灰色禁用状态。

功能逻辑：勾选后，系统将放弃目录内文件的默认排序，随机选取目录中的音频文件进行播放，每次调用可能触发不同文件。

**四、关键逻辑梳理（避免混淆）**

**4.1 总控优先级规则**

「背景音乐」总控复选框未勾选时，所有模式、参数、按钮均不可操作，优先级高于其他所有设置。

**4.2 模式与参数联动规则**

目录模式下，仅「随机应用」参数可勾选；文件模式下，「随机应用」参数强制禁用。

所有带启用复选框的参数（如淡入淡出、原音音量等），需先勾选自身复选框，其对应的调节控件才会解锁可操作。
